# 💰 Student Expense Tracker

A Full Stack Web Application built with Java Spring Boot and MySQL.

## 🚀 Features
- ✅ User Registration & Login
- ✅ Forgot Password
- ✅ Add, Edit, Delete Expenses
- ✅ Filter & Search Expenses
- ✅ Dashboard with Charts
- ✅ Dark Mode 🌙
- ✅ Mobile Friendly 📱
- ✅ Budget Limit Warning ⚠️
- ✅ Export to PDF 📄
- ✅ Export to Excel 📊

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** Maven, Git, GitHub

## ⚙️ How to Run
1. Clone the repository
2. Create MySQL database: `CREATE DATABASE expense_tracker;`
3. Update `application.properties` with your MySQL password
4. Run: `./mvnw spring-boot:run`
5. Open: `http://localhost:8081/login.html`

## 📸 Features Overview
- Login and Register with secure authentication
- Track daily expenses by category
- View spending charts and monthly summary
- Set budget limits and get warnings
- Export data to PDF or Excel
- Toggle Dark/Light mode
